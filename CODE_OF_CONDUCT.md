# Code of Conduct

Athena contributors must communicate respectfully, critique ideas rather than people, welcome
good-faith questions, and avoid harassment, discrimination, threats, sexualized conduct, doxxing,
or disclosure of private repository data.

Maintainers may edit or remove contributions and restrict participation when behavior harms the
community or project. Report conduct concerns privately through the repository owner's GitHub
profile. Reports will be reviewed discreetly and conflicts of interest will be avoided where
practical.

This policy applies in project spaces and when someone is publicly representing the project.
